# ShopLite Registration Form — QA Test Suite

## Project Overview
This project demonstrates foundational software QA skills
through test planning and validation of a fictional e-commerce
registration form.

## Objectives
- Convert business requirements into test cases.
- Cover positive and negative scenarios.
- Document expected and actual results.
- Practice structured defect reporting.
- Communicate testing coverage and limitations.

## Scope
- Required name and email fields
- Email format validation
- Password length validation
- Password confirmation
- Duplicate email handling
- Successful registration

## Requirements
1. Name is required.
2. Email is required and must be valid.
3. Password must contain at least 8 characters.
4. Password confirmation must match.
5. Successful registration displays a confirmation.

## Deliverables
- Registration test cases
- Bug report template
- Test execution results when available
- Screenshots or other test evidence when available

## Tools
- GitHub
- Markdown and CSV
- Browser developer tools (planned)
- Postman and Playwright (future learning)

## Test Status
Initial test design in progress.
No live application execution is claimed at this stage.

## Limitations
ShopLite is a fictional application. Test results will be
recorded only after the scenarios are executed against a
working application.
